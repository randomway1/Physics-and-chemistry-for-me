# Физика и химия для 7–9 классов

Это Android-приложение создано для подготовки по физике и химии.

Что есть в приложении:
- темы по 7–9 классу;
- задачи по физике и химии;
- подсказки с формулами;
- подробное решение задач на русском языке;
- простая структура для быстрого повторения.

## Как открыть в Android Studio
1. Скачайте и установите Android Studio.
2. Откройте папку проекта.
3. Дождитесь синхронизации Gradle.
4. Нажмите Run → app.

## Как собрать APK
1. В Android Studio выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
2. Готовый APK будет в папке `app/build/outputs/apk/debug/`.

## Структура проекта
- `app/src/main/java/com/example/physicschem` — логика приложения и данные
- `app/src/main/res` — строки, цвета, тема и ресурсы
